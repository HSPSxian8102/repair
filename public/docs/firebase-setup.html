1
新增網頁應用程式，取得 Firebase 設定值
這步驟會產生 .env 所需的 API 金鑰與設定
  • 1
    前往 Firebase Console 首頁，確認左上角顯示的是你的專案（例如 Repair-System）
  • 2
    點左側選單最上方的 「專案總覽」，進入專案首頁
  • 3
    在「您的應用程式」區塊，找到平台圖示列，點 </> 圖示（網頁平台，看起來像程式碼符號）
  • 4
    「應用程式暱稱」欄位填入 repair-web（任意命名皆可）
  • 5
    「Firebase Hosting」的勾選框 不需要勾選，我們使用 GitHub Pages 部署
  • 6
    點 「註冊應用程式」 按鈕
  • 7
    畫面會出現一段 JavaScript 程式碼，找到 firebaseConfig 物件，把以下每個值複製下來備用（下一步會用到）
  • 8
    點 「繼續前往主控台」 結束此步驟
程式碼畫面範例（你的值會不同）：
const firebaseConfig = {
  apiKey: "AIzaSyXXXXXXXXXXXXXXXXXXXXXXXX",
  authDomain: "repair-system-xxxxx.firebaseapp.com",
  projectId: "repair-system-xxxxx",
  storageBucket: "repair-system-xxxxx.appspot.com",
  messagingSenderId: "826771XXXXX",
  appId: "1:826771XXXXX:web:XXXXXXXXXXXXXXXX"
};
2
啟用 Google 登入方式
讓使用者可以用學校 Google 帳號登入
  • 1
    點左側選單 「Authentication」
  • 2
    點上方分頁 「登入方式」
  • 3
    在提供者清單中找到 「Google」，點進去
  • 4
    右上角有一個開關，點擊切換為 「啟用」（變成藍色）
  • 5
    「專案的公開名稱」可以填 國立臺南大學附屬高級中學報修系統
  • 6
    「支援電子郵件」選擇 begin@gm.tntcsh.tn.edu.tw
  • 7
    點 「儲存」 按鈕完成
3
建立 Firestore 資料庫
選正式版模式，位置選亞洲
  • 1
    點左側選單 「Firestore Database」（或「Firestore」）
  • 2
    點 「建立資料庫」 按鈕
  • 3
    「選取版本」保持預設（Native 模式）→ 點 「下一步」
  • 4
    「資料庫 ID 和位置」：資料庫 ID 保持 (default)，位置選 asia-east1（台灣/香港最近） → 點「下一步」
  • 5
    「設定」步驟：選 「以正式版模式啟動」（不要選測試模式）
  • 6
    點 「建立」，等待約 30 秒建立完成
⚠
一定要選正式版模式。測試模式雖然方便，但資料庫會對所有人開放 30 天，任何人都可以讀寫，不適合學校系統。我們在下一步會立即套用安全規則。
4
套用 Firestore 安全規則
確保只有學校帳號才能存取資料
  • 1
    在 Firestore 頁面，點上方分頁 「規則」
  • 2
    把編輯框裡的預設內容 全部選取刪除
  • 3
    將下方的安全規則程式碼 完整複製貼入 編輯框
  • 4
    點右上角 「發布」 按鈕
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    function isAuthed() {
      return request.auth != null;
    }
    function isSchoolAccount() {
      return isAuthed() &&
        request.auth.token.email.matches('.*@gm\\.tntcsh\\.tn\\.edu\\.tw$');
    }
    function isAdmin() {
      return isSchoolAccount() &&
        exists(/databases/$(database)/documents/admins/$(request.auth.uid));
    }
    function isSuperAdmin() {
      return isAdmin() &&
        get(/databases/$(database)/documents/admins/$(request.auth.uid)).data.role == 'superadmin';
    }

    match /repairs/{id} {
      allow read: if isSchoolAccount();
      allow create: if isSchoolAccount();
      allow update: if isSchoolAccount() && (
        isAdmin() ||
        (request.auth.uid == resource.data.submittedBy && resource.data.status == 'pending')
      );
      allow delete: if isAdmin();
    }

    match /admins/{uid} {
      allow read: if isSchoolAccount();
      allow write: if isSuperAdmin();
    }

    match /locations/{id} {
      allow read: if isSchoolAccount();
      allow write: if isSuperAdmin();
    }
  }
}
5
在本機建立 .env 設定檔
把 Step 1 取得的 Firebase 設定值填入專案
  • 1
    開啟檔案總管，前往 D:\Repair 資料夾
  • 2
    找到 .env.example 這個檔案，複製一份，改名為 .env（注意：沒有副檔名，就是 .env）
  • 3
    用記事本或 VS Code 開啟 .env，把每一行等號右邊的 your-xxx 換成 Step 1 複製到的對應值
  • 4
    儲存檔案

設定值對應說明

VITE_FIREBASE_API_KEY ← apiKey 的值
VITE_FIREBASE_AUTH_DOMAIN ← authDomain 的值
VITE_FIREBASE_PROJECT_ID ← projectId 的值
VITE_FIREBASE_MESSAGING_SENDER_ID ← messagingSenderId 的值
VITE_FIREBASE_APP_ID ← appId 的值
# D:\Repair\.env 填好後範例（你的值會不同）
VITE_FIREBASE_API_KEY=AIzaSyXXXXXXXXXXXXXXXXXXXXXXXX
VITE_FIREBASE_AUTH_DOMAIN=repair-system-xxxxx.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=repair-system-xxxxx
VITE_FIREBASE_MESSAGING_SENDER_ID=826771XXXXX
VITE_FIREBASE_APP_ID=1:826771XXXXX:web:XXXXXXXXXXXXXXXX
🔒
.env 不可上傳到 GitHub！這個檔案含有私密金鑰。專案的 .gitignore 已經設定好會忽略它，請不要手動移除這個設定。
6
啟動系統並第一次登入
確認系統能正常連線 Firebase，並建立你的帳號紀錄
  • 1
    開啟 命令提示字元 或 PowerShell，輸入以下指令切換到專案資料夾：
    cd D:\Repair
  • 2
    輸入啟動指令：
    npm run dev
  • 3
    畫面出現 Local: http://localhost:5173/ 表示啟動成功
  • 4
    開啟瀏覽器，前往 http://localhost:5173
  • 5
    點「使用 Google 帳號登入」按鈕，選擇你的學校帳號（begin@gm.tntcsh.tn.edu.tw）登入
  • 6
    登入成功後，應該會看到報修清單主頁（目前是空的，這是正常的）
ℹ
這步驟的目的是讓 Firebase 自動建立你的使用者紀錄，這樣下一步才有 UID 可以複製。
7
設定超級管理員帳號
讓你的帳號獲得總務主管最高權限

第一部分：取得你的使用者 UID

  • 1
    回到 Firebase Console，點左側選單 「Authentication」
  • 2
    點上方分頁 「使用者」，此時應該可以看到你剛才登入的帳號出現在清單中
  • 3
    找到你的 Email，同一列最右邊有一欄 「使用者 UID」，是一串英數字（例如 abc123XYZ456def）
  • 4
    點那串 UID 旁邊的 複製圖示，把它複製到剪貼簿備用

第二部分：在 Firestore 新增管理員文件

  • 1
    點左側選單 「Firestore Database」，點上方分頁 「資料」
  • 2
    在最左欄（集合列表區）點 「+ 新增集合」
  • 3
    「集合 ID」欄位輸入 admins（全小寫，完全一樣）→ 點「下一步」
  • 4
    「文件 ID」欄位：把剛才複製的 UID 貼上（不要點「自動 ID」）
  • 5
    新增以下三個欄位（點「+ 新增欄位」逐一加入）：
欄位名稱類型值
emailstring（字串）begin@gm.tntcsh.tn.edu.tw
namestring（字串）你的姓名
rolestring（字串）superadmin（全小寫）
  • 6
    點 「儲存」 完成
  • 7
    回到瀏覽器的報修系統，按 F5 重新整理，導覽列右上角的你的名字旁邊應該出現 總務人員 標籤，代表設定成功
8
新增地點清單資料
提交報修單時的地點下拉選單來源
  • 1
    在 Firestore → 資料 頁面，點 「+ 新增集合」
  • 2
    「集合 ID」輸入 locations → 點「下一步」
  • 3
    「文件 ID」點 「自動 ID」（讓系統自動產生）
  • 4
    依照下表新增欄位，然後點「儲存」。重複此步驟新增多個地點
欄位名稱類型範例值
namestring教學大樓 101教室
buildingstring教學大樓
floorstring1樓
roomstring101
activebooleantrue
💡
建議先新增 5～10 個常用地點（如各棟教室、廁所、走廊、辦公室等）。之後第三期開發的管理後台完成後，就可以在網頁上直接新增地點，不需要再進 Firestore Console 手動操作。
